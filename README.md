## 📌 Sobre o Projeto
O **PortfolioHUB** é uma plataforma centralizada para exibição e gestão de portfólio profissional, desenvolvida em ambiente **Linux** e integrada com esteira automatizada de **CI/CD via GitHub Actions**. Todo o processo de arquitetura, versionamento, segurança e automação contou com a consultoria e suporte do **Google Gemini** como co-piloto de Inteligência Artificial.

---

## 🛠️ Tecnologias e Ferramentas Utilizadas
* **Sistema Operacional:** Linux
* **Controle de Versão:** Git & GitHub
* **Automação (CI/CD):** GitHub Actions
* **Co-piloto de IA:** Google Gemini

---

## ⚙️ Estrutura do Projeto & Esteira CI/CD
A pipeline automatizada foi configurada no ficheiro `.github/workflows/deploy.yml` para garantir verificações de qualidade a cada `push` ou `pull_request` na branch `main`.
